CONFIGURACION CLI PARA SWITCH
================================
enable
configure terminal

vlan 10
 name Office
vlan 20
 name Guest
vlan 99
 name Management

interface range fa0/1-8
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast

interface range fa0/9-10
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast

interface gig0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,99

interface vlan 99
 ip address 192.168.99.2 255.255.255.0
 no shutdown

exit
write memory


CONFIGURACION CLI PARA ROUTER
================================
enable
configure terminal

interface Gig0/0
 no shutdown

interface Gig0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown

interface Gig0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown

interface Gig0/0.99
 encapsulation dot1Q 99
 ip address 192.168.99.1 255.255.255.0
 no shutdown

ip dhcp pool VLAN10
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8

ip dhcp pool VLAN20
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 8.8.8.8

exit
write memory

PASOS EN PACKET TRACER
================================
1. Abre Packet Tracer.
2. Agrega un Router 2911.
3. Agrega un Switch 2960.
4. Agrega un servidor, una impresora, un AP y 8 PCs.
5. Conecta el router al switch.
6. Conecta el switch a los patch panels, server, impresora y AP.
7. Añade 2 laptops inalámbricas conectadas al AP.
8. Configura las IPs y VLANs con las consignas anteriores.
9. Verifica conectividad con ping.
