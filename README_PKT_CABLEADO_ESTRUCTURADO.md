# Topología de cableado estructurado para Packet Tracer

Este archivo acompaña a [cableado_estructurado_suplemento_6_28.pkt](cableado_estructurado_suplemento_6_28.pkt).

## Qué incluye

- Diagrama estructural de telecom room y work areas
- Switch principal, patch panels, servidores, impresora, AP y PCs
- Cables UTP Cat6 y esquema de trabajo por VLAN
- Base para recrear la actividad de lectura del suplemento de Cisco Networking Academy

## Nota importante

El PDF exacto del suplemento no está presente en este workspace, así que esta topología se ha construido con base en los conceptos estándar del cableado estructurado de Cisco: telecom room, patch panels, horizontal cabling, work area y distribución de red.

## Cómo recrearlo en Packet Tracer

1. Abre Cisco Packet Tracer.
2. Crea un switch Catalyst 2960.
3. Añade 2 patch panels y 8 PCs distribuidos en oficinas.
4. Conecta el switch central a cada panel y a servidor, impresora y AP.
5. Asigna VLANs y direcciones IP similares a las indicadas en el archivo .pkt.
6. Verifica conectividad con ping entre workstation, server y printer.
