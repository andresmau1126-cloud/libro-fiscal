TOPOLOGIA REALIZABLE EN PACKET TRACER
====================================

Este archivo es una plantilla funcional para recrear la topología en Packet Tracer.
NO es un archivo .pkt nativo de Cisco, porque ese formato es binario y requiere la aplicación Packet Tracer para generarlo.

OBJETIVO:
- Representar cableado estructurado.
- Mostrar sala de telecomunicaciones, panel de conexión y áreas de trabajo.
- Demostrar conectividad y organización física de la red.

DISPOSITIVOS:
1. Router ISR 2911  -> Internet / gateway
2. Switch Catalyst 2960 -> Sala de telecomunicaciones
3. Firewall / Generic -> Seguridad (opcional)
4. Server -> 192.168.10.10/24
5. Network Printer -> 192.168.10.11/24
6. Access Point -> WLAN / clientes inalámbricos
7. Patch Panel 1 -> Oficinas 1 y 2
8. Patch Panel 2 -> Oficina 3 y Sala de Reuniones
9. PCs: 6 a 8 estaciones de trabajo
10. Laptops / wireless clients: 2 clientes inalámbricos

CONEXIONES SUGERIDAS:
- Router Gig0/0 -> Firewall Gig0/0
- Firewall Gig0/1 -> Switch Gig0/1
- Switch Gig0/2 -> Patch Panel 1
- Switch Gig0/3 -> Patch Panel 2
- Switch Gig0/4 -> Access Point
- Switch Gig0/5 -> Server
- Switch Gig0/6 -> Network Printer

- Patch Panel 1:
  Port 1 -> Office_PC_1
  Port 2 -> Office_PC_2
  Port 3 -> Office_PC_3
  Port 4 -> Office_PC_4

- Patch Panel 2:
  Port 1 -> Office_PC_5
  Port 2 -> Office_PC_6
  Port 3 -> Meeting_PC_1
  Port 4 -> Meeting_PC_2

- Access Point -> Wireless_PC_1
- Access Point -> Wireless_PC_2

DIRECCIONES IP DE EJEMPLO:
- Gateway: 192.168.10.1
- Server: 192.168.10.10 /24
- Printer: 192.168.10.11 /24
- PC 1: 192.168.10.21 /24
- PC 2: 192.168.10.22 /24
- PC 3: 192.168.10.23 /24
- PC 4: 192.168.10.24 /24
- PC 5: 192.168.10.25 /24
- PC 6: 192.168.10.26 /24
- PC 7: 192.168.10.27 /24
- PC 8: 192.168.10.28 /24
- WLAN clients: DHCP o IP manual 192.168.20.x /24

VLAN SUGERIDA:
- VLAN 10: Oficinas / usuarios
- VLAN 20: Invitados / Wi-Fi
- VLAN 99: Management

CONFIGURACION BASE DEL SWITCH:
--------------------------------
interface range fa0/1-8
 switchport mode access
 switchport access vlan 10

interface range fa0/9-10
 switchport mode access
 switchport access vlan 20

interface gig0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20,99

interface vlan 99
 ip address 192.168.99.2 255.255.255.0
 no shutdown

CONFIGURACION BASE DEL ROUTER:
--------------------------------
interface Gig0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown

interface Gig0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown

interface Gig0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown

interface Gig0/0.99
 encapsulation dot1Q 99
 ip address 192.168.99.1 255.255.255.0
 no shutdown

ip dhcp pool VLAN10
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8

ip dhcp pool VLAN20
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 8.8.8.8

VALIDACION:
- Ping de PC 1 a PC 2
- Ping de PC 1 al Server
- Ping de PC 1 a Printer
- Ping de Wireless_PC_1 al AP
- Verificar que la red horizontal y la sala de telecomunicaciones quedan bien conectadas
